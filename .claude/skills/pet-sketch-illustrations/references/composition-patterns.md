# Composition Patterns and Originality Rules

## Basic Structure Types

Choose one structure only per image. Do not mix multiple frameworks.

### 1. Workflow (워크플로)
- Best for input -> process -> output, pipelines, AI/cache flows.
- Layout: raw/messy input on the left, animal operating a strange machine in the middle, crisp output on the right, connected by orange flow arrows.

### 2. System Fragment (시스템 단편)
- Best for caches, queues, filters, databases, retrieval subsystems.
- Layout: draw only 3-5 core low-tech modules, with dog/cat performing one decisive physical action.

### 3. Before/After Contrast (전후 대비)
- Best for messy/ordered, slow/fast, stale/fresh, manual/automated.
- Layout: tangled/rocky/broken state on one side, streamlined state on the other, joined by an orange transition arrow.

### 4. Character State (캐릭터 상태)
- Best for bottlenecks, overload, waiting vs. instant hit, stuck -> moving.
- Layout: 2-3 compact states with short labels showing the physical strain or relief.

### 5. Conceptual Metaphor (개념적 비유)
- Best for abstract mechanisms (cache invalidation, indexing, RAG, compilation).
- Layout: one memorable weird low-tech contraption with a few clear inputs/outputs.

### 6. Layered Method (계층 구조)
- Best for storage tiers, protocol stacks, fallback layers.
- Layout: stacked wooden crates, shelves, or stone well depth—never a sterile corporate pyramid.

### 7. Route Map (경로도)
- Best for request paths, handoff routes, detours around obstacles.
- Layout: curving rocky/dashed path with obstacle breakpoints, dog/cat pulling a thread or bridging a gap.

### 8. Small Comic Sequence (소형 컷 시퀀스)
- Best for multi-step state changes (e.g., origin mutated -> stale cache purged -> next read fetches fresh value).
- Layout: 2-3 tight sequential mini-scenes on white space.

## Original Metaphor Method (Three Steps)

Every time, reinvent a strange, concrete metaphor from the current article. Never settle for plain modern office clipart (like an ordinary office desk drawer, metal filing cabinet, or cylinder office trash can).

### Three Steps
1. **Turn the abstract concept into a physical action**: get stuck, leak, weigh down, yank a cord, crank, ferment, bridge a chasm, snip a thread, pry open a tin box, sweep debris off a shelf.
2. **Turn the system structure into a weird low-tech contraption**: see the Object Pool below.
3. **Put the dog or cat inside the work**: cranking the handle, tangled in the cord, perched on the crate rim snipping a stale tag, hauling across stepping stones, guarding a trapdoor.

### Low-Tech Object Pool
- Hand-cranked presses, stone wells, wooden crates with latches, tin lunchboxes, funnels, balance scales, pulleys & ropes, knotted orange threads, wooden plank bridges over cliffs, glass fermentation jars, mechanical stampers, mail chutes, chutes & trapdoors, clotheslines with clips, rickety ladders, locked iron vaults.
- Pick only 1-2 contraptions per image. Anchor them with crisp black ground lines, pebbles, grass tufts, and parallel ink hatching.

### Character Action Pool
- Pull, haul, crank, snip, yank, plug, scoop, stamp, weigh, pry, bridge, barricade, sweep, intercept, drop down a chute.

## Style Calibration & Repetition Rules

- Open `assets/examples/` ONLY to calibrate ink pen nib roughness, cross-hatching density, solid-black visual weight, ground-line anchors, whitespace balance, and 3-color annotation grammar.
- Do NOT reuse the exact compositions from `assets/examples/` (conveyor breakpoints, sorting trays, fish dissection, thread-to-door, stone well, noodle/idea press, fermentation jar, cliff bridge) unless explicitly requested. Reinvent a fresh contraption tailored to the article.
